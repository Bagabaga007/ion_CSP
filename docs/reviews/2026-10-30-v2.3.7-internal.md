# ion_CSP 2.3.7 internal source review

- Review scope: changes since `V2.3.6-internal-runtime` to the LocalContext VASP file-limit diagnostic, two VASP shell launchers, dispatcher gate, tests, lock/version metadata, and usage/delivery documentation.
- Review date: 2026-10-30 CST.
- Decision: **GO for internal source freeze** after the issues below were repaired and the full offline suite passed. This is not a customer distribution or a real VASP result acceptance.

## Findings and closure

| Priority | Finding | Closure evidence |
|---|---|---|
| High / correctness | Python ignores `SIGXFSZ` and `SIGPIPE`; an opt-in Python-to-VASP `exec` would otherwise change native file-limit behavior. | `vasp_launch_diagnostics.exec_vasp` restores native default dispositions before `execvp`. A native C probe under a 1,024-byte limit exits with `-SIGXFSZ` both directly and through the wrapper, while the wrapper records the rank's limit. |
| Medium / compatibility | The opt-in environment flag could reach SSH/scheduler jobs through `resources.envs`, `source_list`, or remote shell state, even if the submitting process had not set it. | `VaspProcessing` validates LocalContext + Shell before an opted-in submission and writes an explicit `ION_CSP_CAPTURE_VASP_DIAGNOSTICS=0/1` assignment into every VASP Task command. Tests cover remote/default `0`, approved local `1`, and remote opt-in rejection before Submission. |
| Low / test environment | The native signal regression uses system `cc`, which is not a Python package dependency. | `docs/delivery.md` declares `cc` as a required Linux release-test prerequisite; the test fails visibly rather than silently skipping it. |

No open P1/P2 finding remained in the final independent focused review. The helper uses per-attempt random tokens, fixed VASP output basenames, bounded metadata and atomic marker writes; it does not copy POTCAR or raw output contents. The `candidate_at_limit` status is a size-based candidate, **not** proof of the exact failed write descriptor. If VASP removes the file before the post-MPI scan, the marker reports `offender_unconfirmed`.
