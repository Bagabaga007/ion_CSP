## 🎯 核心功能模块

### EE模块（Empirical Estimate）

经验评估模块，用于从SMILES表格生成离子组合。

**主要功能**：

- SMILES分子式转换和筛选
- 基于经验公式的离子组合生成
- 密度和能量估算
- 离子配比优化

**相关文档**：

- [EE模块使用示例](example_usage_EE.py)
- [使用指南 - EE模块部分](usage.md#ee模块使用)

### CSP模块（Crystal Structure Prediction）

晶体结构预测模块，用于从离子组合生成并优化晶体结构。

**主要功能**：

- 基于PyXtal的晶体结构生成
- 机器学习势函数（MLP）优化
- VASP分步优化
- 分子/离子识别和验证

**相关文档**：

- [CSP模块使用示例](example_usage_CSP.py)
- [使用指南 - CSP模块部分](usage.md#csp模块使用)

## 🔧 技术架构

### 工作流程

```
用户输入 → 任务管理器 → [EE模块 / CSP模块] → 结果输出
                ↓
            日志系统
                ↓
            进程监控
```

### 核心组件

1. **任务管理器** (`task_manager.py`)
   - 实时进程监控（PID跟踪）
   - 日志文件自动符号链接
   - 进程安全终止与资源清理

2. **日志系统** (`log_and_time.py`)
   - 分页浏览（10条/页）
   - 模块过滤（CSP/EE）
   - 软链接解析显示实际路径

3. **配置管理**
   - 分层配置合并
   - 默认配置与用户配置融合
   - 配置验证和错误处理
