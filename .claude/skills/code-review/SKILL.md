 # Code Review Skill
 ​
 一键触发代码审查，生成专业的审查报告。
 ​
 ## 使用方式
 ​
 ```
 /superpowers.code-review <文件路径>
 ```
 ​
 或
 ​
 ```
 /superpowers.code-review
 # 然后粘贴代码块
 ```
 ​
 ## 审查维度
 ​
 - 🔐 安全性（SQL注入、XSS、权限等）
 - ⚡ 性能（时间复杂度、数据库优化等）
 - 🛠️ 可维护性（命名、注释、模块化等）
 - ✅ 最佳实践（团队规范等）
 ​
 ## 输出
 ​
 Markdown 格式的审查报告，包含问题列表、严重等级、修复建议。
